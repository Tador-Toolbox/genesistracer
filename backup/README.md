# גיבויים — GenesisTracer

כל תיקייה כאן היא צילום מלא של קוד המערכת בתאריך שבשם התיקייה.

## איך משחזרים
1. בוחרים את תיקיית הגיבוי הרצויה (למשל `backup/2026-09-25/`).
2. מעתיקים את הקבצים ממנה חזרה לשורש הריפו (מחליפים את הקיימים).
3. עושים commit ו-push ל-`main` — Render יעלה את הגרסה המשוחזרת.

## מה לא נכלל
- **`.env`** — סודות (חיבור ל-MongoDB וכו') לא משוכפלים לגיבוי. הם שמורים ב-Environment Variables של Render.
- **נתוני המסד (MongoDB)** — הגיבוי כאן הוא של הקוד בלבד. נתונים (מתקינים, פאנלים, דיירים וכו') יושבים ב-MongoDB Atlas ומגובים שם.

> טיפ: כל גיבוי מסומן גם בתגית git (`backup-YYYY-MM-DD`), כך שאפשר לשחזר גם דרך GitHub → Tags.
